# goit-markup-hw-05

Домашнє завдання №5: форма підписки, модальне вікно та форма заявки.

Запускайте `index.html` через **Open with Live Server** у VS Code або локальний HTTP-сервер, щоб SVG-спрайт завантажувався коректно.

```sh
python3 -m http.server 8000
```

Відкрийте http://localhost:8000.

## Перевірка модального вікна

Модалка прихована за замовчуванням. У DevTools додайте клас `is-open` до елемента `#modal`, щоб показати її; видаліть цей клас, щоб приховати. За умовами цього ДЗ JavaScript не потрібний, тому кнопки відкриття та закриття не перемикають стан автоматично.

Перевірте Tab для фокуса полів, Space для checkbox та зміну кольору рамок і SVG-іконок. Форма підписки й форма заявки є навчальною HTML/CSS-розміткою без підключення до сервісу надсилання.

Стилі модалки розміщено в `css/modal.css`, форми підписки — у `css/footer.css`. Спрайт `images/icons.svg` містить усі 14 символів.
